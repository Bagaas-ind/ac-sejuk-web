Sebuah platform *Landing Page* dan sistem pemesanan (booking) modern untuk layanan jasa service AC **"AC Sejuk TITL"**. Website ini dirancang khusus untuk siswa-siswi **Teknik Instalasi Tenaga Listrik (TITL) SMKN 1 Kab. Tangerang** (Kelas Industri Panasonic).

## 🌐 Live Demo
Cek website yang sudah online di sini: **[ac-sejuk-web.netlify.app](https://ac-sejuk-web.netlify.app)** *(Ganti dengan link Netlify kamu yang asli)*

## ✨ Fitur Utama

- **Desain UI Premium**: Tema *Dark Mode* yang elegan dengan aksen neon (ungu/biru) khas *startup* modern.
- **100% Responsif**: Tampilan dioptimalkan untuk kenyamanan pengguna di HP (Mobile) maupun Laptop.
- **Form Pemesanan Cerdas**: Pelanggan dapat memilih layanan, jumlah unit, dan alamat. Data akan otomatis di-format dan dikirim langsung ke **WhatsApp Admin**.
- **Galeri Dokumentasi**: Menampilkan foto-foto asli pengerjaan service AC oleh para siswa.
- **Skor Performa Tinggi**: Mendapatkan skor **100/100** di Google PageSpeed Insights (Mobile) berkat optimasi gambar dan font dari Next.js.
- **Integrasi WhatsApp**: Tombol *floating* dan tautan langsung ke WA admin.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Bahasa**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Netlify](https://www.netlify.com/)
