Sebuah platform *Landing Page* dan sistem pemesanan (booking) untuk layanan jasa service AC **"AC Sejuk TITL"** oleh siswa **SMKN 1 Kab. Tangerang**.

## 🌐 Live Demo
Cek website yang sudah online di sini: **[https://web-service-ac.netlify.app/  ]** 

## ✨ Fitur Utama
- **Desain UI Premium**: Tema *Dark Mode* dengan aksen neon.
- **100% Responsif**: Nyaman dibuka di HP maupun Laptop.
- **Form Pemesanan Cerdas**: Data pelanggan otomatis dikirim langsung ke **WhatsApp Admin**.
- **Galeri Dokumentasi**: Foto asli pengerjaan service AC oleh para siswa.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Bahasa**: TypeScript
- **Styling**: Tailwind CSS
